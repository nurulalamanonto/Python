# Python Image Slideshow

A simple image slideshow application developed using Python, Tkinter, and Pillow.

## Features
- Displays a collection of images.
- Automatically changes images every 3 seconds.
- Provides a simple graphical user interface.

## Technologies Used
- Python
- Tkinter
- Pillow

## Installation

Install Pillow:

```bash
pip install Pillow
```

## How to Run

1. Clone or download this repository.
2. Make sure the image paths in `main.py` point to the correct image files.
3. Run the application:

```bash
python main.py
```

## Project Purpose

This project demonstrates basic Python programming, GUI development, image handling, and slideshow functionality.
